Scaling the cluster
  `helm upgrade --set replicas=N` does NOT resize the Raft cluster.
  Raft membership is persisted state, changed through the admin API:
    grow:   add the node via the admin console/API (add-voter), THEN
            `helm upgrade --set replicas=N` so the peer list matches.
    shrink: remove-voter first, then lower replicas.
  Rolling updates and node drains wait for each voter to be ready, which
  means it has caught up with the leader, and the PDB protects quorum.
  Keep a voter's volume claim when it is rescheduled: without it the voter
  starts empty and has to catch up before it counts again.
