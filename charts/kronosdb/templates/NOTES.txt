Scaling the cluster
  `helm upgrade --set replicas=N` does NOT resize the Raft cluster.
  Raft membership is persisted state, changed through the admin API:
    grow:   add the node via the admin console/API (add-voter), THEN
            `helm upgrade --set replicas=N` so the peer list matches.
    shrink: remove-voter first, then lower replicas.
  Rolling updates and pod rescheduling need no special handling — node
  IDs and DNS names are stable, and the PDB protects quorum.
